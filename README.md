# MoE_Optimization

Репозиторий содержит исследовательские проекты, связанные с оптимизацией архитектур Mixture-of-Experts (MoE) для больших языковых моделей (LLM). Основное внимание уделяется повышению эффективности и производительности MoE-моделей через различные методы оптимизации.

Направления исследований:

1. Мерджинг экспертов

Оптимизация MoE-моделей через объединение похожих экспертов для ускорения инференса при сохранении качества.

3. Умный выбор экспертов

Повышение качества ответов модели через интеллектуальный выбор специализированных экспертов для конкретных доменов и замены "слабых" экспертов.
