# MoE Optimization

Репозиторий содержит исследовательские эксперименты по оптимизации
архитектур Mixture-of-Experts (MoE) для больших языковых моделей. Основной
фокус - ускорение инференса и снижение вычислительных затрат при сохранении
качества модели.

## Структура

- `common/` - общие реализации MLP-блоков, слияния экспертов, подбора пар,
  метрик и вспомогательных функций.
- `Qwen_MoE_experts_fusion_experiment/` - отдельный пайплайн эксперимента по
  сжатию экспертов модели `Qwen/Qwen1.5-MoE-A2.7B-Chat`. Скрипты запускаются
  по порядку: `1_*.py`, `2_*.py`, ..., `9_*.py`.
- `MoE_auto_bias_experiments/` - отдельные эксперименты с auto-bias для разных
  семейств моделей. Каждый файл соответствует самостоятельной постановке.
- `merging/` и корневые ноутбуки - исследовательские ноутбуки и прототипы.

Эксперименты намеренно остаются в разных файлах и директориях: это упрощает
сравнение подходов и снижает риск случайно смешать разные исследовательские
сценарии.

## Направления исследований

1. Мерджинг экспертов.

   Объединение похожих экспертов для ускорения инференса при сохранении
   качества модели.

2. Умный выбор экспертов.

   Повышение качества ответов через выбор специализированных экспертов для
   конкретных доменов и замену слабых экспертов.

## Стиль разработки

Python-код форматируется `ruff format`. Настройки форматирования находятся в
`pyproject.toml`.
